# ASR 术语与纠错表

`mlx-whisper` 的中文结果可能有同音词和英文术语误识别。整理笔记时，必须结合视频标题、页面标签、上下文和下面的术语表做保守纠错。

## 基本原则

1. 只改正上下文能明确判断的错误，不凭空补全听不清的内容。
2. 无法判断时保留原词，并在对应位置写“待核实”。
3. 技术名词优先使用行业通用写法，保留英文缩写。
4. 口述回答中可以使用纠正后的术语；口述稿或引用式内容必须保持谨慎。

## 已观测到的典型误识别

| ASR 输出 | 在 Agent / 会话上下文中应理解为 |
|---|---|
| Agen / Ager | Agent |
| 绘画 | 会话（如果是 Agent、Session、记忆隔离语境） |
| 绘画 ID | 会话 ID |
| 绘画隔离 | 会话隔离 |
| 群职 | 隔离 |
| RAJV | RAG |
| 采购 | 踩坑（如果是“线上采购”语境） |
| 存储实力 | 存储实例 |
| 弹幕 | Demo（如果是“做弹幕/跑弹幕”的产品语境） |

注意：`绘画` 在美术、设计、图像生成语境下可能是正确词，不能无条件替换。必须先判断视频主题。
